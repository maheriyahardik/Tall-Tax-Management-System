This project demonstrates a basic automated toll tax system using Arduino Uno, an Ultrasonic Sensor, and a Servo Motor. It is designed to automate the toll collection process by detecting approaching vehicles and automatically opening the barrier—reducing manual effort and improving traffic flow.

🔧 Components Used:
Arduino Uno

Ultrasonic Sensor (HC-SR04)

Servo Motor (SG90 or similar)

Jumper Wires

Breadboard

Power Supply

⚙️ How It Works:
The ultrasonic sensor detects an approaching vehicle within a predefined range.

Once detected, the Arduino triggers the servo motor to lift the toll barrier.

After a short delay (simulating vehicle passage), the barrier lowers back automatically.

This process repeats without any manual operation, simulating a real-world automated toll gate.

🎯 Project Highlights:
Simple and beginner-friendly circuit and code.

Great for learning automation, sensor integration, and basic embedded systems.

Ideal as a mini project, science fair demonstration, or classroom assignment.
